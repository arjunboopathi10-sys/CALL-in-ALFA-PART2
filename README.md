# CALL in ALFA

A lightweight, laptop-only video editor that runs in the browser (Chrome or Edge).
Multi-track timeline, trim and split, titles, basic color correction, 720p export.
Your videos stay on your laptop; nothing is uploaded.

## Run
Open `index.html` in Chrome or Edge. No install needed.

## Notes
- Screen width of at least 1024px is required.
- Export runs in real time and produces a `.webm` file.
