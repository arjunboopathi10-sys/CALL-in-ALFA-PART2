CALL in ALFA

A lightweight video editor for low-RAM laptops. Install it once and use it like a normal app, even offline.

Open in browser

If the Install button does nothing

  • Chrome: click the install icon at the right of the address bar, or menu ⋮ → “Install CALL in ALFA”.
  • Edge: menu … → Apps → “Install this site as an app”.

Windows offline package (no browser tab, no internet needed)

Download .zip
Unzip it, then double-click Start CALL in ALFA.bat. It opens the app in its own window using Edge or Chrome.

Requirements

  • Laptop or desktop, screen at least 1024px wide
  • Chrome or Edge
  • Your videos stay on your laptop. Nothing is uploaded.
